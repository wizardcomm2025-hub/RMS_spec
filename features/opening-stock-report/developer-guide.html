Feature developer guide

Report → Opening Stock Report (stock movement)

The index is README.md; use cases are the NN-<use-case>.md files.

What this feature does

Records every stock change in a new stock ledger and reports, for a date range, each item's opening stock, what came in and went out, count adjustments and closing stock at the user's locations, with the movements behind each figure.

v1 scope

dbo.StockLedger + trigger trg_Stock_Ledger on dbo.Stock; type / document / business date from SESSION_CONTEXT set by the rebuilt saving procedures and POS; a one-time seed; the movement report and a movements dialog.

How it works end-to-end

A saving procedure calls sp_set_session_context for StockMoveType, StockMoveRef, StockMoveDate, changes Stock (the trigger writes one ledger row per changed stock row: new − old active quantity in the main unit), then clears the keys. Sp_GetOpeningStockReport sums ledger rows before / within / up to the range; Sp_GetStockMovements lists them with a running balance.

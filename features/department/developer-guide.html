What this feature does

Departments are the teams staff belong to (Kitchen, Service, Bar). Every user has one; roster patterns and rosters are planned per department. This screen keeps the company's list: add, rename, switch on or off — never delete.

v1 scope

Fix the 10-row list limit (also hurting Roster), the duplicate save that showed success, the weak duplicate check, and the usual API gaps; rebuild the page on the list recipe. See README.md.

How it works end-to-end

The page loads the full list once and searches it in the browser. Saves and status changes go through AssetManagementController to stored procedures on DepartmentMaster that check the company, the name and the edit token under a per-company lock. Deactivation is refused while active users or roster patterns belong to the department.

Vehicle Master

Vehicles used for deliveries and inter-location stock transfers.

What this feature is

A Vehicle is an active transport unit (car, van, truck) registered in the company's Tenant DB table dbo.VehicleMaster. Each vehicle has a unique Registration Number (RegNo) and a Manufacturer / Brand Name (BrandName). Supplying locations select active vehicles during Inbound Requisitions and Stock Transfers.

What matters where you sit

RMS API

Endpoints in SettingController and UsersController are secured with [CompanyAuthorize]. Permissions required: create_vehicle_master (add) and edit_vehicle_master (edit, toggle status). Hard delete is blocked; failures return standard { status: false, message: "...", data: null } with sanitized user-facing messages.

Tenant DB

Rows are stored in dbo.VehicleMaster scoped by CompanyId. Status is controlled via IsActive (1 = Active, 0 = Inactive). Updates use UTC timestamps (GETUTCDATE()) and concurrency edit token checking.

Admin Dashboard (Next.js)

The screen lives at src/pages-sections/vendor-dashboard/vehicle-master/ and follows the standard §12 list recipe. It uses PageHeader with an About panel (omitting the duplicate short description), real-time client search across registration and manufacturer, an Inactive filter, and confirmation modals for deactivation.
